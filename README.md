# Image_Processing_alpha_trimmed_mean_filter
denoisng with alpha trimmed filter
- C++ / OpenCV 사용
- Grayscale float image 기반 필터 구현
- 주변 픽셀 탐색, 정렬, 평균 계산 과정을 직접 구현
- 다양한 kernel size와 alpha 값 실험
- Kernel size 및 alpha 변화에 따른 filtering 결과 비교
